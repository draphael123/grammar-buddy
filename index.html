Frequently Asked Questions

Everything you need to know about Grammar Buddy

Does Grammar Buddy work on Slack, Google Docs, and other platforms?

Yes! Grammar Buddy works on virtually any website where you can type text, including:

  • Slack - Works in message boxes and threads
  • Google Docs - Works in the document editor
  • Gmail - Works in email composition
  • LinkedIn - Works in posts and messages
  • Twitter/X - Works in tweet composer
  • Any website with text inputs or editable areas
Is Grammar Buddy really free?

Yes, Grammar Buddy is completely free to use. We use the LanguageTool API which offers generous free usage limits. There are no hidden fees, subscriptions, or premium tiers.

How do I install Grammar Buddy?

Since Grammar Buddy isn't on the Chrome Web Store yet, you can install it manually:

  1. Click "Download Extension" to get the ZIP file
  2. Extract the ZIP file to a folder on your computer
  3. Open Chrome and go to chrome://extensions
  4. Enable "Developer mode" in the top right
  5. Click "Load unpacked" and select the extension folder
What languages are supported?

Grammar Buddy supports over 25 languages including English (US, UK, AU), German, French, Spanish, Portuguese, Dutch, Polish, Russian, and more. You can change the language in the extension settings.

Is my data private and secure?

Your privacy is our priority. Grammar Buddy only sends text to LanguageTool's servers for grammar checking - no text is stored or logged. The extension doesn't collect any personal information or track your browsing activity.

Does it work offline?

Grammar Buddy requires an internet connection to check your text using the LanguageTool API. However, your ignored words and settings are stored locally and will persist offline.
